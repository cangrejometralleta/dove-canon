# Stories Mini

Start with the project's Story index. Then look for other live work in the
current handoff, roadmap, actionable TODOs, open issues or PRs, and
user-named notes or trackers. Use available read access and stop when
further sources are unlikely to change the ranking. Name the sources checked
and any material access gap. Keep private raw notes out of the report.

Deduplicate by outcome. Link the evidence and keep discovered tasks separate
from indexed Stories. Keep blocked work visible and name what would unblock it.

Give each item a state, a priority (high, medium or low), and a complexity
(small, medium or large). Judge priority from impact, urgency and whether it
unblocks other work. Judge complexity from scope, dependencies and uncertainty.
Mark estimates when evidence is thin. Sort by priority and surface up to three
actionable choices, using complexity to break ties. Recommend one with a reason.

Report the indexed count. Around nine active Stories, suggest reviewing or
distilling the list. Keep surveying and allow new Stories above nine.
Keep the survey read-only. For a selected distillation, use long-story-short.
