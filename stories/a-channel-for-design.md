# A Channel for Design (UNDISTILLED)

The Canon Teaches how to Read and write, but not where a Design Learns to
Live. Design needs Change, and no one Door Takes them in. One skill,
`like-to-move-it`, Covers them today under its chosen name.

The Aim is an Architecture so simple and so plain that it stays Maintainable.
The Value already Landed in `values/approaches.md`; what Waits is the Door.

- Conventions Carry the Shape, so Configuration need not.  
  A new Project Copies the Structure of the Example of its Kind.
- An Example is one per Kind and Case, read as a Catalog.
  [The Kinds](../.agents/skills/like-to-move-it/references/design.md#the-kinds)
  is the Table that says which to Copy. School is its API Example.
- A real Codebase Feeds; it does not Govern.  
  What it Teaches Enters as a Story and Climbs only
  if a second Project Agrees.
- One Example is not Universal, and does not Need to be.

Blocked on a second Kind with a working Origin Example.
A Converter is a Candidate. The existing API row Holds the scratch and
real cases of one Kind.

Distill when a second Kind of Example keeps its own Entry in the Catalog.
