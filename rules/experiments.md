# Experiments

> Provisional. Written from practice, not yet Weathered.

- Measure nothing without a Blank.  
  A Gauge that climbs without a negative Control measures Drift, Noise or Memory,  
  never the Change you think you tested.
- Design a Control that must Fail, Stay flat or Notice what is absent.  
  When the Control matches the Treatment,  
  the Instrument lost its Edge before the trial Began.
- Watch for a Ceiling on the Instrument too.  
  A strong Reader scoring every Sample at the top  
  hides the Difference a lighter Reader or a narrower Budget would expose.
- State the Control beside the Result.  
  An experiment that runs only the active Case reports a Story,  
  never a Measurement.

A vessel that Collects gas during a window where the Culture cannot Act  
looks busy if nobody sets an empty Vessel beside it.  
[Tests](tests.md) Checks code the same Way:  
break the Rule, and see whether the Watch still Rings.

This rule is *Provisional*.  
It came from one practice and has not yet Survived a second.
